# Tsunagi host

The program you run on the computer you want to reach from the Tsunagi app (iPhone, iPad, Android).

```
curl -fsSL https://macfixkou.github.io/tsunagi-host/install.sh | sh
tsunagi host
```

- Guide (Japanese): https://macfixkou.github.io/tsunagi-host/
- Privacy policy: https://macfixkou.github.io/tsunagi-host/privacy.html
- Binaries: [Releases](https://github.com/macfixkou/tsunagi-host/releases) — macOS (Apple silicon + Intel), Linux x86_64 / arm64 (experimental)

Questions and bug reports: [Issues](https://github.com/macfixkou/tsunagi-host/issues).

Built on [iroh](https://github.com/n0-computer/iroh) (MIT / Apache-2.0) and [portable-pty](https://github.com/wezterm/wezterm) (MIT).
